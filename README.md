# Facefall Survivor

Browser-based top-down zombie survival shooter. Upload a photo and the game uses it as the hero's face locally in the browser.

## MVP

- top-down survival combat
- pistol, shotgun and bow
- zombie waves, elite enemies, score and health
- face upload processed locally in the browser
- desktop WASD + mouse controls
- mobile touch controls
- no backend required

## GitHub Pages

The repository includes a GitHub Pages workflow. Every push to `main` deploys the static game.

## Roadmap

1. Realistic environment art and character animations.
2. Collision, buildings, doors and loot.
3. Inventory, crafting and weapon upgrades.
4. Character progression and persistent runs.
5. More zombie archetypes and bosses.
6. Better face fitting for the hero model.
7. PWA/offline support.
